# PB 27 Melayu Alang

Checklist tugasan PB (Pentaksiran Berterusan) peribadi untuk pelajar PISMP IPG. Ia satu fail `index.html` sahaja, tanpa pelayan dan tanpa log masuk.

## Ciri-ciri

- Sapaan ikut nama dan waktu, serta quote motivasi yang bertukar setiap hari
- Perasaan hari ini, dengan cadangan tugasan yang sesuai dan rekod 7 hari
- Tugasan dengan jenis (termasuk Peperiksaan), keutamaan, tahap kesukaran, nota dan pautan
- Paparan ikut tarikh, ikut kursus atau ikut keutamaan
- Tema, mod gelap, fon, saiz teks dan warna kursus boleh diubah
- Bahasa Melayu / English
- Butang salin senarai tarikh akhir untuk WhatsApp
- Eksport dan Import (.json) untuk sandaran atau pindah ke peranti lain

## Data

Semua data disimpan dalam `localStorage` pelayar pada peranti itu sahaja. Senarai bermula kosong.
Untuk pindah ke peranti lain, guna **⚙ Tetapan → Sandaran data → Eksport**, kemudian **Import** di peranti lain.
Jika data pelayar dipadam (clear browsing data), senarai juga akan hilang, jadi buat Eksport sekali-sekala.

## Terbitkan di GitHub Pages

1. Log masuk ke github.com dan tekan **+** (atas kanan) → **New repository**.
2. Beri nama, contohnya `pb-alang`. Pilih **Public**. Tekan **Create repository**.
3. Di halaman repositori, tekan **uploading an existing file**.
4. Seret `index.html` dan `README.md` ke situ, kemudian tekan **Commit changes**.
5. Pergi ke **Settings → Pages**.
6. Di bawah **Build and deployment**, pilih **Deploy from a branch**, kemudian branch `main` dan folder `/ (root)`. Tekan **Save**.
7. Tunggu satu atau dua minit, kemudian muat semula halaman Pages. Pautan akan muncul di atas, contohnya `https://<nama-pengguna>.github.io/pb-alang/`.

Untuk kemas kini kemudian, muat naik `index.html` yang baharu ke repositori yang sama.
